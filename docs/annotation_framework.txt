      /INTERMEDIARY CLASS

        (person is intruding into truck bed)

        /MINOR CLASS
        - [BODY_PART] INTRUSION FROM [POSITION]

      - OUT-OF-BED DETECTION
        (person not intruding into truck bed)

        - INTERACTING WITH VEHICLE

    - FALSE POSITIVE (CV)
      (bounding box does not contain a person)

      - GHOST
        (person is not intruding into truck bed)

        - NON-HUMAN OBJECT
        - EXTRAPOLATED PERSON
        - WINDSCREEN SMUDGE
        - LOW LIGHT

      - HAPPY ACCIDENT
        (person is intruding into truck bed)

        - VISIBLE
        - NON-VISIBLE
